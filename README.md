# CardoFE — Global Spice Intelligence React Dashboard

Modern analytics dashboard for **Cardo Board**, featuring interactive time series, climate anomalies, production breakdowns, and parameterized scenario extrapolations.

## Tech Stack
- **React 18 + TypeScript**
- **Vite 5**
- **Tailwind CSS**
- **Recharts**
- **Lucide Icons**

## Features
- **Global Filter Bar**: Switch between Spices (*Small Cardamom, Black Pepper, Nutmeg, Cloves*), Scopes (*World, India, Kerala, Idukki*), and Frequencies.
- **URL-Driven State**: Every view is shareable and reproducible via query params.
- **Extrapolations & Scenario Modeling**: Interactive sliders and fan charts projecting price corridors under weather/monsoon shocks and supply/demand shifts.
- **1-Click Export**: Download filtered data as CSV or JSON.

## Quick Start
```bash
npm install
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000).
